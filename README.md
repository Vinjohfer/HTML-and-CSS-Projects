# HTML-and-CSS-Projects
This repository is for my Academy of Learning Subject
This will contain a collection of web development projects, assignments, and coding exercises completed during my coursework at the Academy of Learning Career College. This repository showcases foundational front-end design, styling techniques, and responsive web development using HTML, CSS, and Bootstrap.

## Projects Included

**Academy Cinemas (`Academy-Cinemas`)**  
  A multi-section cinema showcase website featuring movie listings, showtimes, and booking components.

**Introduction to Bootstrap (`Introduction-to-Bootstrap`)**  
  Exercises demonstrating responsive layouts, grid systems, and utility classes using the Bootstrap framework.

**One-Page Website (`One-Page-Website`)**  
  A clean, single-page landing site designed with structured semantic HTML and smooth section navigation.

**Simple Recipes (`Simple-Recipes`)**  
  A structured food and recipe layout focused on typography, content organization, and media presentation.

**The Pet Shop Website (`The-Pet-Shop-Website`)**  
  A storefront-style web page displaying pet services, products, and contact forms with custom styling.
